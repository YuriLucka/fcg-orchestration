# FCG Fase 4 (Azure) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Colocar a FCG rodando no AKS com ACR e IP público, busca fuzzy com Elasticsearch no CatalogAPI, CI/CD com rolling update para UsersAPI/CatalogAPI e nenhuma credencial em código ou YAML.

**Architecture:** Fase A (local, custo zero) limpa credenciais nos 4 repos e implementa a busca; tudo é validado com `docker compose`. Fase B sobe a infra na Azure por script `az` versionado, aplica os manifests e cria as pipelines GitHub Actions que aplicam o `k8s/` de cada repo com a imagem do commit. Fase C produz README, roteiro e relatório.

**Tech Stack:** .NET 8, xUnit + Moq, Elastic.Clients.Elasticsearch 9.x, Docker Compose, Kubernetes (AKS), Azure CLI, GitHub Actions, Kong 3.7, RabbitMQ 3, SQL Server 2022, MongoDB 7, Redis 7.

**Spec:** `fcg-orchestration/docs/superpowers/specs/2026-10-16-fase4-azure-design.md`

## Review Focus

- Busca com termo vazio ou só espaços → 400 com mensagem, nunca 500. (Task 4)
- Elasticsearch fora do ar durante create/update/delete → CRUD responde normalmente, só loga. (Task 4)
- Elasticsearch fora do ar durante a busca → 503, não 500. (Tasks 4 e 5)
- Elasticsearch fora do ar no boot → API sobe mesmo assim (reindex com timeout). (Tasks 4 e 5)
- `JwtSettings:SecretKey` ausente ou vazia → API falha no boot com mensagem clara, em vez de erro na primeira requisição. (Tasks 2 e 3)

```csharp
        {
            if (string.IsNullOrWhiteSpace(query))
                throw new DomainException("Informe o termo de busca.");

            try
            {
                return await _search.SearchAsync(query.Trim());
            }
            catch (Exception ex)
            {
                _logger.LogError(ex, "Falha ao consultar o Elasticsearch (termo '{Query}').", query);
                throw new SearchUnavailableException(ex);
            }
        }

        public async Task EnsureSearchIndexAsync()
        {
            try
            {
                var games = await _gameRepository.GetAllAsync();
                await _search.EnsureIndexAsync(games.Select(MapToDto));
            }
            catch (Exception ex)
            {
                _logger.LogWarning(ex, "Falha ao preparar o índice de busca no Elasticsearch. A API segue sem reindexar.");
            }
        }
```

`src/Catalog.Infrastructure/Search/ElasticGameSearchService.cs`:

```csharp
using Catalog.Application.DTOs;
using Catalog.Application.Interfaces;
using Elastic.Clients.Elasticsearch;
using Elastic.Clients.Elasticsearch.QueryDsl;
using Microsoft.Extensions.Options;

namespace Catalog.Infrastructure.Search
{
    public class ElasticGameSearchService : IGameSearchService
    {
        private readonly ElasticsearchClient _client;
        private readonly string _index;

        public ElasticGameSearchService(ElasticsearchClient client, IOptions<ElasticsearchSettings> settings)
        {
            _client = client;
            _index = settings.Value.IndexName;
        }

        public async Task IndexAsync(GameDto game, CancellationToken ct = default)
        {
            var response = await _client.IndexAsync(game, _index, game.Id, ct);
            EnsureValid(response.IsValidResponse, response.DebugInformation);
        }

        public async Task RemoveAsync(Guid id, CancellationToken ct = default)
        {
            var response = await _client.DeleteAsync(_index, id, ct);
            if (!response.IsValidResponse && response.Result != Result.NotFound)
                throw new InvalidOperationException(response.DebugInformation);
        }

        public async Task<IReadOnlyList<GameDto>> SearchAsync(string query, CancellationToken ct = default)
        {
            var request = new SearchRequest<GameDto>(_index)
            {
                Size = 20,
                Query = new MultiMatchQuery
                {
                    Query = query,
                    Fields = new[] { "title^3", "description" },
                    Fuzziness = new Fuzziness("AUTO")
                }
            };

            var response = await _client.SearchAsync<GameDto>(request, ct);
            EnsureValid(response.IsValidResponse, response.DebugInformation);
            return response.Documents.ToList();
        }

        public async Task EnsureIndexAsync(IEnumerable<GameDto> games, CancellationToken ct = default)
        {
            var exists = await _client.Indices.ExistsAsync(_index, ct);
            if (exists.Exists)
                return;

            var create = await _client.Indices.CreateAsync(_index, ct);
            EnsureValid(create.IsValidResponse, create.DebugInformation);

            var docs = games.ToList();
            if (docs.Count == 0)
                return;

            var bulk = await _client.BulkAsync(b => b
                .Index(_index)
                .IndexMany(docs, (op, doc) => op.Id(doc.Id)), ct);
            EnsureValid(bulk.IsValidResponse && !bulk.Errors, bulk.DebugInformation);
        }

        private static void EnsureValid(bool valid, string debugInformation)
        {
            if (!valid)
                throw new InvalidOperationException(debugInformation);
        }
    }
}
```

Nota para o implementador: se algum nome não compilar na versão 9.x instalada (ex.: overload `IndexAsync(doc, index, id, ct)` ou `BulkAsync` com `IndexMany`), usar o equivalente da mesma major mostrado pelo IntelliSense — o comportamento exigido é: indexar com `_id = game.Id`; deletar por id ignorando 404; `multi_match` em `title^3`/`description` com `fuzziness AUTO`, ordem padrão por `_score`; criar índice só se não existir e então bulk.

```bash
: "${MSSQL_SA_PASSWORD:?}" "${JWT_SECRET:?}" "${RABBIT_USER:?}" "${RABBIT_PASS:?}" "${ES_URL:?}"

echo "== Infra"
az acr update -n "$ACR" --sku Basic -o none
az group create -n "$RG" -l "$LOCATION" -o none
if ! az aks show -g "$RG" -n "$AKS" -o none 2>/dev/null; then
  az aks create -g "$RG" -n "$AKS" -l "$LOCATION" \
    --tier free --node-count 1 --node-vm-size Standard_D4as_v5 \
    --max-pods 50 --node-osdisk-size 64 \
    --auto-upgrade-channel none --node-os-upgrade-channel None \
    --attach-acr "$ACR" --generate-ssh-keys -o none
fi
az aks get-credentials -g "$RG" -n "$AKS" --overwrite-existing

echo "== Imagens ($TAG)"
az acr login -n "$ACR"
for api in users catalog payments; do
  img="$ACR.azurecr.io/$api-api:$TAG"
  docker build -t "$img" "$REPOS/fcg-$api-api"
  docker push "$img"
done

echo "== Secrets"
kubectl apply -f "$ROOT/k8s/namespace.yaml"
apply_secret() { kubectl -n "$NS" create secret generic "$@" --dry-run=client -o yaml | kubectl apply -f -; }
apply_secret users-db-secret   --from-literal=MSSQL_SA_PASSWORD="$MSSQL_SA_PASSWORD"
apply_secret catalog-db-secret --from-literal=MSSQL_SA_PASSWORD="$MSSQL_SA_PASSWORD"
apply_secret rabbitmq-secret   --from-literal=RABBIT_USER="$RABBIT_USER" --from-literal=RABBIT_PASS="$RABBIT_PASS"
apply_secret payments-secret   --from-literal=RabbitMq__User="$RABBIT_USER" --from-literal=RabbitMq__Pass="$RABBIT_PASS"
apply_secret users-secret \
  --from-literal=ConnectionStrings__DefaultConnection="Server=users-db;Database=users;User Id=sa;Password=$MSSQL_SA_PASSWORD;TrustServerCertificate=true" \
  --from-literal=JwtSettings__SecretKey="$JWT_SECRET" \
  --from-literal=RabbitMq__User="$RABBIT_USER" --from-literal=RabbitMq__Pass="$RABBIT_PASS"
apply_secret catalog-secret \
  --from-literal=ConnectionStrings__DefaultConnection="Server=catalog-db;Database=catalog;User Id=sa;Password=$MSSQL_SA_PASSWORD;TrustServerCertificate=true" \
  --from-literal=JwtSettings__SecretKey="$JWT_SECRET" \
  --from-literal=RabbitMq__User="$RABBIT_USER" --from-literal=RabbitMq__Pass="$RABBIT_PASS" \
  --from-literal=MongoSettings__ConnectionString="mongodb://mongodb:27017" \
  --from-literal=RedisSettings__ConnectionString="redis:6379" \
  --from-literal=Elasticsearch__Url="$ES_URL" \
  --from-literal=Elasticsearch__ApiKey="${ES_APIKEY:-}"
envsubst '${JWT_SECRET}' < "$ROOT/kong/kong.yml" \
  | sed -e 's#http://users-api:8080#http://users-api#' -e 's#http://catalog-api:8080#http://catalog-api#' > /tmp/kong.yml
apply_secret kong-config --from-file=kong.yml=/tmp/kong.yml
rm -f /tmp/kong.yml

echo "== Manifests"
for f in users-db.yaml catalog-db.yaml mongodb.yaml redis.yaml rabbitmq.yaml kong/deployment.yaml kong/service.yaml \
         payments-api/configmap.yaml payments-api/service.yaml; do
  kubectl apply -f "$ROOT/k8s/$f"
done
sed "s/IMAGE_TAG/$TAG/" "$ROOT/k8s/payments-api/deployment.yaml" | kubectl apply -f -
for api in users catalog; do
  dir="$REPOS/fcg-$api-api/k8s"
  kubectl apply -f "$dir/configmap.yaml" -f "$dir/service.yaml"
  sed "s/IMAGE_TAG/$TAG/" "$dir/deployment.yaml" | kubectl apply -f -
done

echo "== Aguardando"
for d in users-db catalog-db rabbitmq users-api catalog-api payments-api kong; do
  kubectl -n "$NS" rollout status deployment/$d --timeout=600s
done
echo "IP público do Kong:"
kubectl -n "$NS" get svc kong -o jsonpath='{.status.loadBalancer.ingress[0].ip}'; echo
```

```yaml
name: ci-cd

on:
  pull_request:
    branches: [main]
  push:
    branches: [main]

concurrency:
  group: deploy-users-api
  cancel-in-progress: false

env:
  ACR: acrfiapyuri
  RG: rg-fcg
  AKS: aks-fcg
  NS: fcg
  APP: users-api

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-dotnet@v4
        with:
          dotnet-version: 8.0.x
      - name: Testes unitários
        run: dotnet test tests/Users.Tests/Users.Tests.csproj -c Release

  deploy:
    if: github.event_name == 'push'
    needs: test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: azure/login@v2
        with:
          creds: ${{ secrets.AZURE_CREDENTIALS }}

      - name: Build e push da imagem (tag = commit)
        run: |
          TAG=sha-${GITHUB_SHA::7}
          IMG=$ACR.azurecr.io/$APP:$TAG
          az acr login --name $ACR
          docker build -t $IMG .
          docker push $IMG
          echo "TAG=$TAG" >> $GITHUB_ENV

      - uses: azure/aks-set-context@v4
        with:
          resource-group: ${{ env.RG }}
          cluster-name: ${{ env.AKS }}

      - name: Secret da API
        run: |
          kubectl -n $NS create secret generic users-secret \
            --from-literal=ConnectionStrings__DefaultConnection='${{ secrets.DB_CONN }}' \
            --from-literal=JwtSettings__SecretKey='${{ secrets.JWT_SECRET }}' \
            --from-literal=RabbitMq__User='${{ secrets.RABBIT_USER }}' \
            --from-literal=RabbitMq__Pass='${{ secrets.RABBIT_PASS }}' \
            --dry-run=client -o yaml | kubectl apply -f -

      - name: Deploy (rolling update)
        run: |
          sed -i "s/IMAGE_TAG/$TAG/" k8s/deployment.yaml
          kubectl apply -f k8s/
          kubectl -n $NS rollout status deployment/$APP --timeout=300s
```
